Ballasting

Buoyancy and Ballasting Calculation Example

  1. Measured Quantities

    Dry mass of glider (measured on a floor scale, out of the water):

    \[ m_{\text{dry}} = 101.4\,\mathrm{kg} \]

    Water density during ballast test (measured at the test location):

    \[ \rho_{\text{water}} = 1022.9\,\mathrm{kg\,m^{-3}} \]

    Hanging scale measurement (apparent weight in water):

    (positive means the glider is still heavy in water)

    \[ m_{\text{wet}} = +0.209\,\mathrm{kg} \]

    Additional mass required to make the glider sink:

    \[ m_{\text{added}} = 0.346\,\mathrm{kg} \]

  2. Determining the Displaced Water Mass

    When an object is submerged, the buoyant force equals the weight of the displaced water. In mass units, this corresponds to the total mass of water displaced by the glider.

    The displaced water mass is calculated as:

    \[ m_{\text{disp}} = m_{\text{dry}} + m_{\text{wet}} - m_{\text{added}} \]

    \[ m_{\text{disp}} = 101.4 + 0.209 - 0.346 = 101.537\,\mathrm{kg} \]

  3. Calculating Glider Volume

    Using the definition of density:

    \[ \rho = \frac{m}{V} \Rightarrow V = \frac{m}{\rho} \]

    \[ V = \frac{m_{\text{disp}}}{\rho_{\text{water}}} = \frac{101.537}{1022.9} = 0.099264\,\mathrm{m^3} = 99.264\,\mathrm{L} \] This is the physical volume of the glider.

  4. Density of the Glider (Current Configuration)

    The effective density of the glider is its dry mass divided by its volume:

    \[ \rho_{\text{glider}} = \frac{m_{\text{dry}}}{V} = \frac{101.4}{0.099264} = 1021.52\,\mathrm{kg\,m^{-3}} \]

    Since this value is lower than seawater density, the glider is positively buoyant.

  5. Target Density and Required Mass

    Target neutral-buoyancy density:

    \[ \rho_{\text{target}} = 1022.8\,\mathrm{kg\,m^{-3}} \]

    The mass required for neutral buoyancy at this density is:

    \[ m_{\text{target}} = \rho_{\text{target}}V = 1022.8 \times 0.099264 = 101.527\,\mathrm{kg} \]

  6. Ballast Adjustment Required

    The required ballast change is the difference between the target mass and the current dry mass:

    \[ \Delta m = m_{\text{target}} - m_{\text{dry}} = 101.527 - 101.4 = +0.127\,\mathrm{kg} \]

    Interpretation:

    A positive value means mass must be added. Therefore, 127 g must be added to achieve neutral buoyancy at \(1022.8\,\mathrm{kg\,m^{-3}}\).

  7. Key Takeaways

    • Always track units at every step.
    • Water density must match the ballast test environment.
    • If glider density \(<\rho_{\text{water}}\), the glider floats.
    • Small mass changes (\(O(100\,\mathrm{g})\)) significantly affect buoyancy.

Tank Ballasting Procedure

  1. After applying vacuum to 6 for G2, 7 for G3 +- 0.3 inHg, ballast glider
  2. Supplies are in yellow ballasting box
    1. Water pump
    2. Red winch
  3. Open ballasting tank, put metal across top
  4. Hang scales and fishing line
  5. Connect Freewave wireless data receiver
  6. Connect Green plug
    1. CTRL C
    2. Put c_air_pump 0
    3. Callback 30
    4. Lab_mode on
    5. Use - argos iridium attitude_rev (disable argos iridium and compass)
    6. Ballast
  7. Put the glider in the water and add wings, making sure the entire glider, including the antenna, is under water.
  8. Remove sensor caps (salinity and 02)
  9. Shake to remove bubbles from glider, particularly from the nose
  10. Flush the salinity sensor using the aquarium pump
  11. Raise glider off of scales, zero scales, and put back on fishing line near black part of glider
  12. Measure weight on front and aft after letting the water in the tank settle down
  13. Test science instrument, get water temp and salinity
    1. Report clearall
    2. Put c_science_all_on 0 (turn on science instruments)
    3. Put c_science_send_all 1
    4. Report ++ sci_water_temp (continuously record temp)
    5. Report ++ sci_water_cond (continuously record salinity)
    6. Report clearall
  14. Save ProComm buffer (to use in script when calculating average temp and salinity
    1. Edit -> scrollback buffer to -> clipboard
  15. Power down glider
    1. Exit reset
    2. CTRL C
    3. Put c_air_pump 0
    4. Exit

Compass Calibration

  1. Gather compass calibration supplies
    1. Freewave
    2. Computer with ProComm
    3. Rope with carabiner
    4. Ladder
  2. Hang glider from rope as high as possible
  3. Connect Freewave to computer and battery power
  4. Open ProComm, confirm serial cable 1 (port 3) (this is the 2 port blue serial cable)
  5. Connect Green plug
    1. CTRL C
    2. Put c_air_pump 0
    3. Callback 30
    4. Lab_mode on
    5. Use - argos iridium (disable argos and iridium)
    6. Exit pico (G2) / exit shell (G3) exit to picoDOS)
    7. Talk att (G2) / talk attitude (G3) (begin reading compass)
  6. Close teraterm
  7. Open Revolution app, using the same port as teraterm
    1. Wireless
    2. Close
    3. Tools -> Calibrate magnetics -> start
    4. Confirm setting
      1. 3D
      2. 3000 samples
      3. 64 something?
  8. Begin spinning glider in every orientation possible
    1. X,Y,Z planes in Revolution app will begin to be populated
    2. If at OOI, do 300 observations flat with the glider upright, then 300 with the nose down, then 300 with the nose up. Flip the glider sideways and complete this process for 900 more observations, then flip the other way and repeat.
    3. Get 3000 observations
    4. If more than 3% mag sigma, redo
    5. Use new (saves file)
    6. This file is saved directly to the glider
    7. Write down the change in Mag Total sigma 3 values for future reference.
  9. Open teraterm, it should automatically connect via the same port
    1. Enter
  10. If at OOI and doing a compass characterization:
    1. App -lab (to go back into gliderdos)
    2. Callback 30
    3. Put c_iridium_on 0
    4. Put c_argos_on -1
    5. Put c_gps_on 0
    6. Report ++ m_vacuum m_coulomb_current m_heading
      1. Once m_vacuum is steady and m_coulomb_current is 0.15 amp or less it indicates that the air pump motor is no longer running and the air bladder is full. Then remove those 2 variables from reporting
    7. Report - m_vacuum m_coulomb_current
    8. Close teraterm
    9. Start compass program (python program)
  11. After compass characterization
    1. App -lab
    2. Report clearall
    3. Put c_de_oil_vol -1000 (if deep pump)
    4. Put c_air_pump 0
    5. exit
  12. Pull green plug (because we’re in picoDOS, no need to exit)

Battery Charging

  1. There are two ways to charge lithium batteries depending on what model glider they are in.
  2. If the glider is a newer G3 with an external charging port:
    1. Connect the charging cable to the external port at the aft end of the glider
    2. Turn on the charging block
      1. The amperage reading should increase initially, up to ~12
      2. The glider is done charging once the readout is less than 0.5 amps
  3. If the glider is a G2, the forward and aft batteries will need to be removed to charge (ex SL592)
    1. Take glider apart to access both the forward and aft batteries
    2. The charging cable has three direct charging cables corresponding to the aft, extended battery, and forward battery (the cable is identical for the forward and extended battery).
    3. Use the charging cable adaptor to plug in to the aft battery first, and then use either of the remaining charging cables to plug into the forward battery.
    4. Turn on the charging block
      1. The amperage reading should increase initially, up to ~12
      2. The glider is done charging once the readout is less than 0.5 amps
  4. When either replacing G2 batteries or after recharging G3 batteries, reset the coulomb counter to 0
    1. Put m_coulomb_amphr_total 0
    2. Exit reset
    3. Get m_coulomb_amphr_total
  5. You can also check the lithium battery relative charge
    1. Get m_lithium_battery_relative_charge
  6. Other relevant battery commands
    1. m_battery
    2. m_battery_inst
    3. m_coulomb_amphr_total
    4. m_coulomb_current
    5. M_lithium_battery_relative_charge
    6. report ++ m_bms_pitch_current m_bms_aft_current m_bms_ebay_current
    7. get m_bms_emergency_battery_voltage

Talk to Battery

  1. You can directly query the battery in two ways:
    1. With the batteries in the glider
      1. Exit pico (G2) / exit shell (G3) exit to pico/shell DOS
      2. Talk batt (G2) / battery (G3)
    2. With the batteries outside the glider
      1. Connect the charging / communication cable to the batteries
        1. Open TeraTerm and connect via available serial port
        2. You will only see a black screen, even when you type commands
        3. Type $R,0 $R,1 $R,2 or $R,3 (R,2 is for extended battery)
      2. The output will look similar to this:
        $R,0
        Batt #: 0
        Status: 0xdc10
        LTCO: 0x202
        Voltage: 5009 mV
        Current: 0 mA
        Temperature: 296.101562K
        Serial: 1425
        Remaining Capacity: 0 mAh
        Full Charge Capacity: 9915 mAh
        Time to full charge: -1 min
        Cycle Count: 3
        Thermistor (raw) 32320
        Thermistor (V) 2.465880
        Manufacturer Name: INSPIREDE
        Device Name: NL2054HD34
        Device Chemistry: LION
      3. The important part is that the full charge capacity on the rechargeable batteries is over 9000 mAh. There will always be a ‘dummy’ battery in $R,0 that will say something like this (and this is normal):
        Remaining Capacity: -1 mAh
        Full Charge Capacity: -1 mAh
      4. It is common to have to query a battery multiple times to get a ‘full’ reading, meaning that some of the Batt # will not communicate properly if only querying the battery 1 time.
    3. Ctrl -c
    4. App -lab (to go back into gliderdos)
